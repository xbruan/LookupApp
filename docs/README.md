# `docs/` —— 设计依据与工程记录

本目录放**决策与依据**，不放进度、待办、当前实测结果那类会过期的表。
五块内容：

| 路径 | 是什么 |
| --- | --- |
| `adr/` | 架构决策记录（ADR）：一条硬规则为什么这么定、落地约束是什么 |
| `api/abi.md` | 接口定义的可读版（**自动生成**，逐条函数 / 参数 / 返回 / 错误码） |
| `design/` | 设计文档：每个功能模块的决策、信任边界、API 来源与理由 |
| `code-review-2026-09-29.md` | 0.2.1 所依据的安全 / 工程审查报告 |
| `审查处置记录-0.2.1.md` | **那份报告里每一条发现，0.2.1 怎么处置的、拿什么证明**（一条对一条） |

## `api/abi.md`

由 `abi/lookup.abi.json` 经 `node tools/gen-bindings.mjs` 生成，与 `native/include/dsh_lookup.h`、
`shell/Lookup.Interop/DshLookup.g.cs`、`web/src/shared/abi.ts` 同一批产物。
**不要手改**；改接口定义后重新生成，检查用 `node tools/gen-bindings.mjs --check`。

## `design/`

| 文件 | 决定什么 |
| --- | --- |
| `术语表.md` | **用词标准**：一个词在这个项目里指什么、什么时候用、什么时候不许用（"旧词 → 新词"的对照表） |
| `不带mdd的词典与机器翻译开发指导.md` | **不带 `.mdd` 的词典**（`.mdx` 旁边散放 css / 字体 / 图片 / **`.js`**）：`.mdd` 优先、同目录兜底，以及放行 `.js` 这一次信任边界变更的范围与理由；**机器翻译**：只绑豆包、与语音共用一把 Key 但权限独立、32 种语种的映射与不支持的语种必须如实失败 |
| `查词兜底通道与历史记录开发指导.md` | **查词通道**：每次查询走到「当前词典 → 借查别本 → 机器翻译 → 终态页」的尽头；「没问完」与「没有」绝不含糊；**历史记录**从"一个词"升级成"一个词 + 它当时在哪本词典里"，以及词典被移除 / 文件丢失时怎么如实说 |
| `发音功能设计.md` | **三层音源**（词典自带录音 → 在线 → 系统离线）的顺序与选择、词典自带录音怎么找、增益与响度怎么算，以及界面与内核的分工 |
| `豆包语音合成接入方案.md` | **在线语音（豆包 · 单向流式 HTTP）**：端点与四个头、音色与模型版本的配套关系、中英混排为什么必须走中文音色、SSE 回包怎么解析、错误码怎么翻成人话 |
| `输入框右键菜单改走原生编辑命令.md` | 输入框的**剪切 / 复制 / 粘贴 / 全选必须走原生命令**（`document.execCommand`），**不许**直接给 `dom.input.value` 赋值（程序性赋值不进浏览器撤销栈）；菜单项必须继续用 `mousedown` + `preventDefault()` |
| `图标设计与改进指导.md` | **任何视觉改动之前必须走的流程**：图标是几何图形不是文字，`stroke-width: 1.7` / 16px 画布下"最小可辨特征 ≈ 4.2px"这条量化约束，结构自检 → 出图 → **交人看图**三步验收，以及"不要做的事" |

`design/` 下的每一份文档都在**文末**带一节 `## 来源与整理说明`：说明它迁自哪里、
清掉了哪些只对旧工作目录成立的引用，以及（如有）更正了哪些已经与代码不符的断言。

## `code-review-2026-09-29.md`

0.2.1 的出发点。它是**定向审查**，不是全量渗透测试：安全与可靠性发现（F1 词典脚本可触发翻译动作、
F2/F3 解析器的整数溢出与过早分配、F4/F5 构建与生成物检查）、文档漂移、以及"是否保留旧版本 /
具体要补回什么 / 是否合并目录"三个问题的结论与迁移顺序。

**它记的是审查当时的状态**，不是现在的状态：其中几条已经被修掉，修法与回归检查落在
相应的 `design/` 文档与 `native/`、`tools/` 里（例如 F1 的授权边界修复与它的 A′ 级回归检查
`tools/check-entry-auth.mjs`）。要判"某一条现在修没修"，**看代码与检查，不看这份报告**。

## `审查处置记录-0.2.1.md`

**报告与处置的对应关系**：F1–F5 逐条写清"报告说了什么 → 我们做了什么 → 拿什么证明 → 怎么自己复验"，
