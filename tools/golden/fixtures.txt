# tools/run-golden.sh（C 侧：跑当前 C 内核 + 与冻结基线比对）与
# tools/make-golden.ps1 / tools/run-golden.sh --regen（C# 侧：**只在显式再生基线时**跑）
# 都读这一份；比对由 tools/golden/compare-golden.py 做（逐字节 + 一张"已确认差异"白名单）。

# Windows 的 .NET 也接受 / 分隔符）。以 # 开头的行与空行被忽略。
